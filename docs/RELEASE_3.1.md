## PixelPanel Studio 3.1 – first public release 🎉

LED panel dashboard for Home Assistant (ESP32 + HUB75): design pages in your browser, see a pixel-exact preview, push them via ESPHome.

**Highlights**
- New **Home Assistant app** – runs in the sidebar, no token needed
- New pages: **Calendar** (list like on your phone), **Chart**, **Scrolling text**
- **Text too long?** Choose per page: scroll, shorten or hide
- One **text-size slider** incl. a tiny **Mini** font
- Umlauts, **€** and **°** on the panel
- **Stay signed in (30 days)** and a list of signed-in devices
- All open browsers stay in sync

**Download**
- **PC version (Windows/Mac/Linux):** `PixelPanelStudio_3.1.zip` below → unpack → `Start.bat` / `start.sh`
- **Home Assistant app:** *Settings → Apps → App store → ⋮ → Repositories* → `https://github.com/Bitax/pixelpanel-studio`
- **Manual:** `PixelPanel_Manual_EN_3.1.pdf` · `PixelPanel_Handbuch_DE_3.1.pdf`

Full functionality requires Home Assistant. The app works on HA OS / Supervised – on HA Container/Core use the PC version.
